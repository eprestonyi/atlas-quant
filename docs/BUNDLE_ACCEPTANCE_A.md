## 实际存储与浏览器

同一份大 bundle 通过真实 Miniflare D1/R2 绑定完成 36 片上传、验证、原子提交、摘要、分页和下载。上传约 3.8 秒，finalize 约 184 毫秒，最新记录约 38 毫秒。25 行页面约 22.6 KB；每次只解码一片并保留匹配行，页面最多读取 8 片。时延是本机样本，不是云端 SLA。

实际浏览器连接上述服务，通过全部历史 / 已成熟筛选（19,400 条）、第二页（26–50）、独立预测详情、模型训练区间和来源身份核对。点击完整报告下载取得 32,994,262 字节，SHA-256 与生成时原始报告一致：`0c6eaf474bf1c4c8c3fd59c7d9bce7dc6e34fea5576c47715b941cd6e8f14a88`。模拟接口的窄屏视觉检查与这个实际存储验收分别保留，不混为同一证据。

另一个小实验走实际 Python runner → 本地 HTTP → Worker → D1/R2；隔离子进程仅返回加密 spool 句柄，随后原片上传。冻结预测的独立重放未重新取数或拟合：104 笔成交、118 日账本，标准库 5,064 项审计通过；最终 ACK 后加密投递目录清空。预测身份为 `66b3e19cb623050ecdce8150b0f72ef9691bacaad0df2db72eb858927e44c9c6`。这是合成输入，不能作为策略有效性证据。

独立故障测试覆盖 R2 写入后取消、租约到期、已验证但未提交不可读、数据库提交回滚、相同内容跨任务隔离及执行篡改来源覆盖计划。浏览器导出为完整报告/预测 JSON；manifest 与 chunks 目录目前由本地 CLI 导出，尚无用户侧云端目录打包按钮。
