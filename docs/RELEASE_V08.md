# v0.8 — 自助财务采集与可复现数据组件

状态：**v0.8 已部署并开放自助财务采集**。2026-10-08 UTC，Worker `0.8.0-107f4acc4485` 与三个 Python 0.8.0 常驻服务已读回；整项 Atlas Quant 重构仍在进行，托管财务状态到 F 的绑定尚未开放。

## 用户流程

财务输入工作区新增自助来源入口：选择公司、年报期间、观察区间和所需状态，核对具体来源请求及已冻结缓存，再提交获取任务。任务完成后进入独立的输入校验、单位与版本、状态定义、准备与证据页面。

首个明确范围为一到两只同交易所沪深证券、一个已结束的十二月年报、最多 366 日的日历。每只证券固定取得利润表、资产负债表、现金流量表，另取得一份交易日历，最多七次来源请求。页面不将该范围描述为全部历史、季度数据或完整 TTM。相应历史依赖不足时保留缺失。

未经核验的单位不会自动成为有效状态。用户可以明确记录单位假设并生成独立输入版本；原输入和原准备结果保留，假设始终带有未核验标识。数据准备成功不代表预测有效，也不自动触发模型训练。

## 模块边界

- 新采集服务具有独立队列、进程和加密恢复目录；原财务准备进程继续没有供应商凭据。
- 固定请求、授权范围、原始响应回执与规范化包相互绑定。代理返回的 HTTP 实体字节不冒称供应商原始网络字节。
- 新请求发送前保存意图；响应保存后才能解析及交付。结果未知时保留人工核对状态，不能换任务重复取数。丢失提交确认只重传已有字节。
- 已撤回授权或改变授权范围的非终态任务不能继续读取缓存、发布新输入。已返回原始响应的保留和终态确认恢复仍可进行。
- 新入口先限定测试工作区，再显式切换公共访问；跨工作区队列和每日新请求预算在数据库写入时共同约束。缓存命中及相同回执重传不再次占用来源请求额度。
- 数据组件核心、打包/解包/重新组成 CLI 与独立标准库审计器提供完整来源闭包。托管 datasetRef 和财务状态接入预测研究仍待后续纵向实现，当前保持关闭。

## 已有验收证据

本地真实 HTTP、Worker、D1/R2 与 Python consumer 联调使用明确标记的合成来源，未调用真实 Tushare。曾出现输出提交被拒绝；修复后使用同一任务及已保存输出恢复，供应商测试调用次数不增加。

实际浏览器完成来源计划、获取、刷新恢复、输入校验和状态准备。严格单位政策得到零条有效及三条缺失；填写两个明确测试单位假设后生成新版本，得到两条有效及一条披露前缺失。逐字段事件为 100/100=1，两个依赖均为用户声明且 unitVerified=false。原严格版本再次读取仍是零条有效，声明版刷新仍为两条有效。浏览器原生事件下载 4,873 字节，SHA-256 `d94ba16edd1076a158402d318601849de4e1ed3feb8c29ea7473d16a5fe74222`；390×844 窄屏页面未出现整页横向溢出。

离线数据组件使用此前冻结的真实两公司材料，不重复读取供应商或拟合 F。完整归档 1,067,520 字节，datasetRoot `6bd0919a71d9f84d2850028d9a854db47c247c663cf01fb9ee5fc2f8b843f9c7`；CLI 打包、解包与重新组成均保持身份。独立标准库审计器使用 33 份外部证据引用完成 67,482 项核对。该核对不认证 PDF 真伪，也不声称重新计算了全部十六种财务公式。

真实网页验收使用贵州茅台 2024 年报和 2025 年观察区间：先冻结四项请求，再实际读取交易日历与三张报表。四项回执、输入与日历共九个文件从 D1/R2 读回；独立标准库比较通过 455 项，核对了代理 HTTP 实体、归一化表格和交易日历。此证据不等同于 Tushare 原始网络字节或原始数值词法。
