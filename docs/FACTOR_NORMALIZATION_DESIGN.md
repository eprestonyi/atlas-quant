# 全池条件模型与因子标准化：设计讨论

2026-10-09。用户要求一个票池使用一个模型，支持个股、参考股票、行业、指数和市场输入。本文是下一版数值协议的设计，**不是已实现或已验证的模型**。原 A 股 PCA 策略尚未定位；课程 PCA + Ridge 不能当作该策略。

后续实现的类型化输入变换、全局日期作用域、训练折清洗及 `atlas-model-function/2` 以 [自动因子预处理协议](AUTOMATIC_FACTOR_PREPROCESSING.md) 为准。本文仍保留尚未实现的参考股票自动接入、波动率目标尺度及 PCA 研究设计，不应据此认定这些扩展已经上线。

## 三层变换不能混为一谈

1. 经济口径：价格变成收益率、相对均线距离或估值偏离；成交量变成相对历史量、换手率等。分红、拆股、复权和时点口径要单独版本化，不能靠 z-score 修复错误原始单位。
2. 输入处理：每个特征声明 transformation、scope、lookback、availableAt 和 missing policy。训练折估计截尾界、填充值、中心和尺度；测试折只能应用已保存参数。按时点更新的历史波动率只能用当时已知历史。不能用完整数据先标准化再切分。
3. 输出/残差尺度：预测变化除以原点已知的正尺度。一个尺度用于拟合目标、价格还原与误差诊断，必须随预测保存，不能改用未来实现波动率。

当前 `atlas-model-function/1` 使用 `scale = sum(abs(q_j * p_j,t))`（已知总绝对腿价值），不是波动率。单股 q=1 时标签是相对当前价格的变化，已具有收益率口径。新增波动率目标必须新版本化，不能修改旧预测或归档的含义。

## 共享函数与显式输入作用域

```text
y_hat[i,t,h] = G_theta,h(
  own_features[i,t], sector_features[sector(i),t],
  market_features[t], reference_features[t], asset_context[i,t]
)
```

同一 theta 为全票池联合拟合。参考股票因子先按该股票自身时间序列计算，再在同一时点广播到研究成员；其来源证券不必是输出成员。行业、市场与指数输入必须引用真实 PIT 观测或明确构建规则，不能用目录名称冒充已接入数据。

全局特征在同一天对所有股票相同，不能做横截面 z-score；它会被消为零或变成零方差。通常沿时间维度变换后广播。个股特征是时间标准分、当日横截面相对分或保留原比例，由研究假设决定。行业内标准分和全市场标准分也必须分开。

Pooled 线性模型中，共享全局特征若要表达不同股票的系统风险响应，需要资产暴露/行业交互或其他明确条件结构；重复同一个市场值并不自动学到所有股票不同 beta。特征及作用域都进入函数身份。

## 单资产收益率目标

对正价格与固定目标时点，定义算术收益及原点可知的期限波动尺度：

```text
r[i,t,h] = (P[i,target] - P[i,t]) / P[i,t]
y[i,t,h] = r[i,t,h] / sigma_hat[i,t,h]
r_hat = sigma_hat * G_theta,h(X)
V_hat = P_t * (1 + r_hat)
e = P_t - V_hat
E = e / (P_t * sigma_hat) = -G_theta,h(X)
u = (r_realized - r_hat) / sigma_hat
```

sigma_hat 是信息集 I_t 下的正数，因此价格还原保持条件期望目标。其估计方法、窗口、最少观测和零波动处理必须显式固定；sqrt(h) 缩放只在声明相应相关性假设时使用。当前旧协议目标是下一开盘再加 h 个交易日，与观察日直接加 h 不同，需单独保存 targetTiming。

E 是标准化的**预测偏离**；u 是之后才观测到的**预测误差**。两者不是同一随机变量。标准化后可以比较经验分布、分位数和联合表，不因此获得正态、独立或平稳假设。PCA 的同期回归残差又是第三种量，不能混用。

篮子净值可能为零或负数，不应除以净价差 P。可用原点总绝对腿价值乘其同口径波动尺度，或者直接使用篮子价格变化的正条件尺度。尺度过小明确拒绝或使用预声明下限，不事后修数。

如果目标先扣掉市场/行业收益，输出首先是超额/残差收益。还原绝对预期价格必须加回相同期限系统项的条件预测，否则应将输出明确命名为对冲状态/篮子的条件值。预测 log-price 时 exp(E[log P]) 一般也不等于 E[P]，不能省略反变换偏差。

## PCA 均值回归闭环

标准化收益矩阵可用于训练窗口内 PCA，确定共同变化空间，再计算资产的共同成分和剩余项。PCA 只做分解，不证明剩余项将回归。需要另行定义可回归的残差状态 x（例如对冲残差累计状态），并检验其动态：

```text
x[t+1] - mu = phi * (x[t] - mu) + noise[t+1]
E[x[t+h] | I_t] = mu + phi^h * (x[t] - mu)
expected_residual_change = (phi^h - 1) * (x[t] - mu)
```

0 < phi < 1 对应单调回归假设，|phi| < 1 是 AR(1) 平稳条件。phi 必须在训练数据中估计并通过独立顺序样本外检查，不是由 PCA 推出的常数。一天的不可预测收益残差不能仅因名称叫“残差”就设为可交易均值回归状态。把预期残差变化映射回固定目标及同口径价格，才形成用户要求的 F、V 和 e。
