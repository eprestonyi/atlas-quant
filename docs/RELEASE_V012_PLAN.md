# v0.12 factor transformation release

## Scope

New research uses the versioned `auto-factor-preprocess/2` contract. Economic
quantity inference applies to compound expressions as well as bare fields.
Prices become declared returns; percent values become fractions exactly once;
size, valuation and monetary quantities have separate documented transforms.
Studio choices are frozen in the research and portable function. Easy uses
the registered defaults. Unknown units require an explicit choice.

Individual-asset state features use conventional returns, return volatility
and relative state deviation. Signed frozen baskets retain changes divided by
known gross value. Single-source foreign factors are computed on their retained
source observations before as-of projection onto the China research calendar.
Repeated marks are therefore not invented zero source-session returns.

The processing report displays the economic formula and the exact training
clipping, imputation, centering and scale parameters. Old `/1` studies keep
their original arithmetic and report labels. No existing research is rewritten.

## Required evidence

The acceptance contract is [FACTOR_TRANSFORM_ACCEPTANCE.md](FACTOR_TRANSFORM_ACCEPTANCE.md).
Independent raw-data calculations, engine parity, catalog semantics, portable
function parity, actual browser behavior and deployment are separate checks.
The original baijiu snapshot is reused without re-requesting Tushare. An
independent Yahoo spot comparison has its own limited request journal and is
not represented as complete source verification. Previously observed terminal
data cannot become a fresh prospective test by rerunning it with new software.

## Deployment

This is a package-only native-service change: no dependency, configuration,
database migration or research queue policy change is planned. Before mutation,
pin the current Worker/settings, all six service identities, engine bytes,
shared environment, requirements, configurations and plists. Save the candidate
from a clean commit and require its Linux push and pull-request checks.

After an empty-queue readback, pause only the three currently active queues.
Stop all six services, confirm process absence and acquire their service/compute
locks. Atomically exchange the staged engine packages while retaining old
packages. The dependency environment and plists remain byte-verified. Deploy
the pinned Worker, start and verify six new processes with explicit `/2`
capability, then restore the original three active queues. All mutations have
unique durable intent; uncertain outcomes are inspected before any continuation.

Perform a new bounded production acceptance with an explicit new research ID,
inspect the deployed Easy/Studio and processing report, verify the exact
downloaded function, and publish the pinned tracked source archive. Private
market data, provider responses and credentials are excluded from public source.
Strategy/execution capabilities remain as previously configured.
