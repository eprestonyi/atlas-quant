# 三种机械残差基线：固定样本真实数据评估

本次在同一份真实 Tushare 数据上，比较运行前固定的三个默认模板。篮子均值残差和 PCA 残差均亏损；PCA 加风格暴露的净收益为 **+0.70%**，但这一单窗结果**不能认定为显著优势或有效 alpha**。三个结果全部保留，没有按收益重挑股票池、区间、参数或模板。

这是 Atlas Quant 0.3.0 的**本地真实数据研究验收**，不作为生产队列、持续服务或实盘融券可执行性的证明。报告整理时间为 2026-10-07 17:03:20 UTC（香港时间 2026-10-08）。执行与数学定义见 [机械篮子残差研究](STAT_ARB.md)；数据使用边界见 [DATA.md](DATA.md)。

## 固定输入与公平比较

固定股票池共 8 只，顺序如下；未重建历史指数成分，也不代表具有行业分散性的市场样本：

```text
000001.SZ  000002.SZ  600000.SH  600036.SH
600519.SH  000333.SZ  000651.SZ  600900.SH
```

| 项目 | 本次设置或实际读回 |
|---|---|
| 请求区间 | 2023-01-01 至 2025-09-30（`20230101`—`20250930`） |
| 共同留出报告区间 | 2025-02-10 至 2025-09-30（`20250210`—`20250930`） |
| 来源 | `TUSHARE_PRO`，`synthetic=false` |
| 接口 | `trade_cal`、`daily`、`adj_factor`、`daily_basic` |
| 输入规模 | 5,336 行，667 个官方交易日；每个模板均有 162 个留出日账日期 |
| 取数 | 一次数据加载，内部共 25 次供应商请求；同一数据帧用于全部模板 |
| 风格字段 | `pb`、`total_mv` 在该输入中的非空覆盖率均为 100% |
| 起始资本 | 1,000,000 元 |

三个模板来自 [scripts/presets.mjs](../scripts/presets.mjs)，本次只将股票池与请求日期设为上述固定值，其余模板默认规则保持不变。

| 模板 ID | 方法 | 附加对冲暴露 |
|---|---|---|
| `basket_mean_residual` | 篮子等权共同成分残差 | 无 |
| `pca_residual` | PCA 共同成分残差 | 无 |
| `pca_style_residual` | PCA 共同成分残差 | `small_size`、`book_yield` |

共同规则为：形成窗 126 个交易日、残差窗 60 日、重新拟合间隔 20 日；PCA 保留 2 个成分；入场 z 阈值 2、退出阈值 0.5、止损阈值 4、最长持有 20 个交易日、AR(1) 半衰期上限 60 日。每日观察、每日允许一般调仓，篮子权重偏离带为 25 bps；目标 gross 为 1、目标净权重为 0。附加暴露启用绝对相关阈值 0.9 的去冗余。

`small_size` 和 `book_yield` 在这里是形成截止日的截面对冲暴露，不用于人工挑选 TopN 股票或预测单股明日收益。等权共同成分基线仅移除等权截面共同成分，不等于对异质股票 beta 的市场中性回归。

所有模板使用同一费用情景：佣金 2.5 bps、滑点 3 bps、卖出税 5 bps、过户费 0.1 bps、每笔最低佣金 5 元；理论借券年费 300 bps，按 252 个交易日分摊。费用是固定研究假设，没有复刻历史税率或某券商报价。

## 全部结果

下表为共同留出窗口的结果，净收益已扣除交易与理论借券费用。Sharpe 使用日收益及 252 日年化、零利息现金基准；“成交笔数”是逐腿研究成交数，不是完整残差往返交易的数量。

| 模板 | 留出净收益 | Sharpe | 最大回撤 | 累计成本（元） | 研究成交笔数 |
|---|---:|---:|---:|---:|---:|
| 篮子均值残差 | −9.06% | −2.111 | −11.37% | 40,595.14 | 1,054 |
| PCA 共同成分残差 | −6.50% | −1.830 | −7.87% | 41,689.61 | 1,144 |
| PCA + 风格因子残差 | +0.70% | 0.237 | −4.34% | 32,799.37 | 1,024 |

PCA 加风格相对独立 PCA 的本次净收益差为 **+7.20 个百分点**。风格报告内部同时运行的无风格 PCA 基线，其全部 `metrics` 与独立 PCA 报告**完全相等**；共同数据、费用、留出边界的检查也全部通过。这支持比较口径一致，不证明因子具有因果贡献或统计显著性。

| 模板 | 零费用反事实收益 | 反事实与实际净收益差 | 累计费用 / 初始资本 |
|---|---:|---:|---:|
| 篮子均值残差 | −5.19% | 3.87 个百分点 | 4.06% |
| PCA 共同成分残差 | −2.39% | 4.11 个百分点 | 4.17% |
| PCA + 风格因子残差 | +4.02% | 3.32 个百分点 | 3.28% |

零费用反事实保持相同信号日程并重新运行账本；资本路径变化会影响后续交易数量，因此“反事实收益差”不等于“累计费用 / 初始资本”。前两种规则在零费用反事实下仍亏损；第三种的正收益在加入费用后明显缩小。

## 独立账本检查

三份结果均独立重算有符号成交现金流、佣金/滑点/税费/过户费、逐日借券费、累积持仓与每日估值恒等式。现金最大绝对误差为 0，权益恒等式最大误差为 `1.1641532182693481e-10` 元，持仓数量最大误差为 `5.4569682106375694e-12` 个研究单位；累计费用与上述报告值一致。

每份报告保留 1,296 条信号事件，本次均未触发 5,000 条上限。目标暴露中性不代表持仓始终精确中性：三种规则实际净敞口绝对值的最大值分别为 1.17%、1.29%、1.71%，实际 gross 最大值分别为 1.033、1.045、1.025。价格变化与费用会使实际暴露偏离目标。

## 适用边界

- 这是固定 8 股和一个留出窗口的描述性比较，没有执行显著性检验、跨市场稳定性验证或未查看区间的前向验证。收益为正、优于另一基线、账本对上，都不等于有效 alpha。
- 模板参数在此次运行前固定，三种结果均报告；这不保证整个研究项目不存在更早的人工尝试。以后据此修改参数，会消耗该留出窗口的独立性。
- 多空篮子使用理论借券和小数复权研究单位。没有核实实际券源、保证金、融资利息、强制买回、手数、盘口容量或涨跌停排队，不能将结果解释为 A 股现金账户可执行收益。
- 信号形成遵守过去数据截止，交易最早在下一开盘，long 持仓遵守 T+1、缺价腿使整篮等待；这些执行规则不消除历史供应商数据修订或固定股票池选择偏差。`daily_basic` 历史修订及发布完整性未获独立验证。
- PCA 与 AR(1) 半衰期诊断不构成协整证明，也不证明残差必然收敛。附加因子仅增加形成期对冲约束，不能自动称为 alpha。
- 本次结果的状态均为 `UNVALIDATED_THEORETICAL_STAT_ARB`，`qualified=false`、`deploymentQualified=false`。本文件不作投资推荐，也不据此选择“最佳策略”。
