# 数据来源与可用时间

FD 指 FinancialDB，包含四个并行的逻辑数据库。它们定义事实归属，不要求部署为四套服务器。

| 数据库 | 所有权 | 本版已验证接入 |
| --- | --- | --- |
| PCD | 公司公开披露、原文证据、不可变观察值、选值版本 | 只读记录、来源与历史选值连接；完整字段目录可检索 |
| MKT | 价格、成交量、报价、汇率等市场记录 | Tushare 日行情、复权因子、交易日历、daily_basic 以及证券池成员 |
| EXT | 外部研报、一致预期、第三方估计及供应商财务序列 | Tushare 财务供应商适配器已通过真实研究；可导入带逐行可用日期的自有数值序列，外部研报与一致预期托管数据尚未验证 |
| MODEL | 内部计算、预测、估值和情景 | Quant 生成可审计的研究结果；支持带来源记录与逐行可用日期的自有模型数值导入，既有 MODEL 数据库的托管历史连接尚未验证 |

SERVING 是四库组合查询层，不是第五个事实库。Memory DB 保存方法、偏好与经验，不提供当前财务事实。Tushare 财报接口属于供应商适配器，不等于 FinancialDB 本身；兼容的 `fd_` 因子别名或 `FD` 筛选键也不定义第五个数据库。供应商财报没有被自动写入 PCD，更不会覆盖 PCD 的原始披露值。

## 已验证的数据边界

截至本次读取，PCD 当前目录含 1,936 类记录、17,073 个字段，其中 4,870 个 decimal/integer 字段具有数值类型资格。目录规模不等于公司、期间或历史数据覆盖。生产中已观察到的事实仅有 Apple 的三个财务字段；目前没有已映射的 A 股公司事实。三字段真实只读连接已经通过，未知公告时间采用系统获知时间，首次保守可用交易日为 2026-10-05。Apple 不在当前 A 股行情适配器范围，不能把它的事实套到 A 股证券。

Tushare 已取得 5,911 个证券身份、5,572 个当前上市身份，生成 1,354 个至少含三只证券的真实成员池，覆盖行业、地域、交易所、交叉分类、申万三级分类及六个常用指数。完整成员与来源哈希保存在目录。首页导航精选只按研究对象的清晰程度和代表性选择；推荐计算子集只是证券代码升序前 20 只，不代表收益排名。当前分类与成员快照不能证明历史成员资格，报告保留幸存者偏差提示。

## 财报与 PCD 对齐

Tushare `fina_indicator` 按显式字段请求 21 项指标。公告日期后的首个官方交易日才可进入特征矩阵，不能按报告期末回填。较旧报告期的迟到修订不能替换较新报告期；缺失值不填零。同证券、公告日、报告期和字段出现冲突版本时，该披露字段隔离为 null，并保留冲突数量、样本、哈希与提示，其余有效字段可以继续计算。供应商是否完整保留最初发布的版本仍未独立验证。

`income`、`balancesheet`、`cashflow` 的真实读取也已通过；本版自动财务因子对齐来自 `fina_indicator`，不能把其他接口的可读性描述成全部字段已经可计算。

PCD 连接必须显式指定字段、单位，以及证券—主体—记录映射。读取不可变观察值与选值历史，以原文发布时间、取得时间、观察值时间、选值时间及记录创建时间的最大值确定可用时间，再推迟到下一交易日。UNKNOWN 发布时间不能回填历史。同证券不同报告期的记录可以共同使用；同报告期多口径、重复对象和不同币种需要先明确选择或聚合。精确十进制原值保留在 PCD，研究矩阵显式转换为 float64。

自有结构化数值可使用 `pcd_`、`ext_`、`model_` 别名，以及兼容的 `fd_` 别名，在同一因果表达式中与 MKT 行情字段组合。每列均需 `provenance.externalFields` 中的数值类型、非空来源与记录路径、`point_in_time_asof` 政策，以及逐行 `<alias>__available_date`。非空数值的可用日期不能晚于信号日；字符串和布尔值不会自动变成事实数值。MODEL 输入还明确保留原模型训练记录未独立核实的审计边界；仅上传一个过去日期不构成训练无泄漏证明。选择 Tushare 时，未实现的 EXT/MODEL 字段会明确要求自有数据导入，不会伪造托管值。

## 运行与复现

私有运行配置中的 `provider_access` 和 `pcd_access` 只在运行进程内注入，不进入浏览器策略、队列或报告。配置必须在仓库外并使用 0600 或更严格权限。PCD 客户端只允许固定的已登记 HTTPS 主机及 GET 读取；Tushare 只允许登记的只读接口。网络错误、权限不足、截断和数据缺口不会触发合成数据回退。

本地命令支持 `scripts/local-run.py strategy.json --source tushare --config /absolute/private/config.json --output result.json`。运行上限为 50 只证券、110,000 行数据、24 MiB 上传与结果、900 秒任务预算。计算子进程终止、取消及回传重试不会重放已经完成的计算。

脱敏源验证记录见 `data/source-validation.json`，PCD 覆盖边界见 `data/pcd-coverage.json`。一次真实验收已完成三只 A 股、2,001 行行情、动量及两项公告日财务因子、八类模型的 14 个候选配置。接口可达、目录覆盖、实际观察值、历史时点可用性与完成回测是分别记录的证据。
