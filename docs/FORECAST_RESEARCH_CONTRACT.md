# 预测驱动的因子研究协议

决策日期：2026-10-08。状态：**v0.4 候选源码已实现主要协议，仍在完整验收；生产发布需另行读回**。

本协议依据用户本轮明确要求：先用具有经济机制的模型估计指定期限的未来价格或可交易相对价差，再通过独立执行层评价交易。不得把纯信号或预先写好的仓位规则直接接入核心研究回测，也不得把现有 z-score 改名为预测。

本文件约束实现；当前精确接口见 [STATISTICAL_QUANT_SCHEMA.md](STATISTICAL_QUANT_SCHEMA.md)，测试与剩余缺口见 [REBUILD_PLAN.md](REBUILD_PLAN.md)。[CONTRACT.md](CONTRACT.md)、[STAT_ARB.md](STAT_ARB.md) 仍记录 v0.3 的实际行为。本文不是新功能完成、测试或部署的证据。

## 统一目标与符号

在观察时点 t，可用信息为 I_t，预测期限为 h：

```text
V_hat[t,h] = F_h(X_t; fitted_parameters)
          ≈ E[P_target | I_t]
edge_gap[t,h] = P_reference[t] - V_hat[t,h]
expected_change[t,h] = V_hat[t,h] - P_reference[t] = -edge_gap[t,h]
forecast_error[t,h] = P_realized[target] - V_hat[t,h]
realized_price_change[t,h] = -edge_gap[t,h] + forecast_error[t,h]
```

V 是模型估计的未来市场价格条件均值，不要求是当前内在价值。F 的经济假设、目标定义和预测期限必须明确。估计值不等于已知的真实条件均值；预测误差是否存在系统偏差要用未参与拟合的数据检查。

edge_gap 是下单前能计算的预测价差；forecast_error 在标签成熟后才可观察。二者不得都称为“残差”而混用。预期价差不是已经获得的利润，实际账本还包含入场价格差异、融资、费用、现金分配和对冲腿。

对于相对价值研究，以有定义的篮子状态 S 替换 P：V_hat = E[S_target | I_t]。首版目标采用冻结数量，记录篮子成员、固定计量单位、数量、价格尺度和构建版本。同一预测的当前状态、目标值、实现标签使用同一个冻结的目标定义。固定权重且持续再平衡的组合必须另立目标类型并定义自融资现金账户，不能直接用权重乘价格冒充其组合价值。不得将不同时点重新拟合的 PCA 坐标直接相减，也不得将累计投影对数收益伪装成以货币计量的可成交篮子价格。

一个可核对的候选定义是冻结研究数量 q_t，令 S_u^(t) = q_tᵀP_u；同一预测的所有 u 使用相同 q_t。固定数量期间的毛价格盈亏为 q_tᵀ(P_exit − P_entry)。换篮子须真实记账。价差可能为零或负，尺度归一使用 gross notional 等有效基准，不能除以价差本身。

若使用总收益调整价格或含分红的目标，必须记录相应处理；不能将除息造成的价格下降当作可赚取的误价。若目标是对数价格，指数化条件均值不是价格条件均值，转换必须处理分布与 Jensen 偏差。

## 研究逻辑

每个模型须声明：信息如何影响目标、关系为什么可能持续或修复、适用期限、失效条件，以及可验证的预测含义。回测评价该假设，不替代经济机制。没有机制说明的裸趋势规则不进入本项目核心研究模板。

动量外推可以预测未来价格或收益；事件模型可以根据事件信息及已发生反应估计剩余调整；基本面模型必须把价值判断转换为指定期限的价格/价差预测，不能直接把长期估值当作 h 期预测。模型名称不替代这些要求。

PCA 仅提取共同成分或构造残差状态，本身不推导均值回归，也不是未来预测。一个可选的下一层模型是：

```text
x[t+1] = a + phi*x[t] + innovation[t+1]
E[x[t+h] | I_t] = phi^h*x[t] + a*sum(phi^j, j=0..h-1)
```

该条件期望表达需要创新条件均值为零等明确假设。phi 和 a 必须按时间因果拟合。允许在研究开始前声明均值回归的参数约束，但必须披露，并与非均值回归基线进行样本外比较；不得把约束后的估计值或半衰期当作过程已平稳的证据。PCA 残差状态、可交易篮子和该预测输出之间还必须有可核对的映射。

“统计套利”是本项目相对价值研究方向。采用相同 F 接口并不自动使单资产方向预测成为套利；中性约束、风险补偿、可借券与实际盈亏需要另外检验。

## 分离的研究与执行层

```text
点时数据 → 因子/状态构造 → F_h 拟合 → 按日期的样本外预测产物
                                      ↓
                               预测诊断与因子增量比较
                                      ↓
                         独立交易策略 → 实际成交与费用账本
```

1. 因子/状态层只输出时点可知的特征及定义、单位、来源和可用时间。预测特征与用于控制风险的对冲暴露分开标识；增加一个投影暴露不等于增加一个预测因子。
2. 预测层输出 V_hat、预测目标、期限及模型版本。可先研究预测，不要求一定生成交易。不支持输出可校准预测的模型不能冒充已完成因子预测研究。
3. 预测诊断优先评价 F_h。新增因子在同一股票池、目标、时间划分、基线模型及调参预算下比较；基准至少包含无变化/零变化预测。
4. 执行层只能消费有效预测产物，结合预计成本、预测不确定性、对冲约束、风险限制及交易阈值形成指令。阈值、仓位与观察/调仓频率不是 F 的替代品。
5. 安全退出、取消过期指令、到期减仓可以在预测缺失时触发；不得因预测缺失而新开仓或扩大风险。每次动作记录预测引用或独立的风险退出原因。

因子研究的主要研究对象是 F_h，但标签、期限、信息时点、目标映射和验证方法同样属于研究协议。单一均方误差不完整刻画尾部风险与交易价值，预测评分和执行评分分别呈现。

## 必须保存的预测产物

字段名称在 API 实现时版本化，以下语义不可省略：

| 内容 | 必需语义 |
|---|---|
| 身份 | forecastId、模型族与版本、modelFitId、因子版本、数据快照与来源 |
| 时间 | observationTime、informationCutoff、训练/验证区间、horizonSessions、目标起止时点、日历 |
| 目标 | targetKind、priceBasis、单位、证券或冻结篮子的定义与版本 |
| 数值 | currentState、expectedFuture、edgeGap、expectedChange |
| 可信程度 | 不确定性方法与参数（未实现时明确缺失）、适用状态与无效理由 |
| 成熟标签 | realizedFuture、forecastError、labelMaturedAt；未成熟时保持缺失 |
| 执行关联 | forecastId、预计费用/借券情景、下单门槛、交易或不交易原因、真实成交引用 |

完整预测序列保存为可下载的私有研究产物；界面预览若截断，明确标注总数及截断范围。不能只保留已交易或最终盈利的预测。

## 时间与检验

- 先定义观察时点、可用信息截止、首个允许成交时点和预测目标时点。h、观察频率、重新拟合频率、调仓频率及最长持有期是不同参数。
- 如果 t 收盘才知道信号，t 的收盘价只能作为预测参考，不能当作已经能够成交的入场价格。持仓收益从真实可用的入场时点开始核算。
- 交易门控必须估计入场后的剩余预期毛收益 E[S_exit − S_entry | I_t]，不能把不可获得的隔夜收益算作剩余 edge。可以联合估计 E[S_exit | I_t] 与 E[S_entry | I_t]，或在允许且已有信息的执行时点重新评价剩余 edge。旧路径的“下一开盘至未来开盘收益预测”不能直接乘当前收盘价并标为严格的未来价格条件均值。
- 保留 A 股 long 数量取得当日不得卖出的 T+1 约束。目标期限与首个允许退出时点冲突时，该预测可用于研究，但不能据此模拟不可成交的同日买卖。不得把目标日期未兑现的价格当成交价。
- 停牌或不可成交造成入场延迟时，预测目标日期不自动顺延；按预先声明的规则取消、失效或生成新预测。
- PCA、缩放、去相关、特征选择、动力学参数和超参数选择都需要各自的训练截止。所有用于拟合的标签在该截止时已经成熟。
- 顺序训练/验证/终端测试，按目标时间跨度清除跨边界标签；同一天的股票不得拆到不同时间集合。因子筛选和重复实验记录选择偏差。
- 清除跨界标签并不使重叠 h 日标签独立。若报告显著性或置信区间，需处理时间重叠与同日截面相关，例如使用适当的日期块重采样；不能将股票乘日期的行数视为独立样本数。
- 用固定目标定义比较实际未来值；模型重拟合不会改写旧预测。缺失或未成熟标签不前填。
- 预测报告至少包含偏差、MAE/RMSE、相对朴素基线的改善、不同期限/状态的稳定性；排序目标才使用适配的截面排序指标。方向正确率不能替代盈亏幅度。
- 策略报告另列成交、成本、借券假设、敞口、净值、回撤和预测到订单的关联。预测有改善不自动等于净交易收益为正。

## 当前代码差距与实现顺序

本轮只读核对的 v0.3 行为：

- `engine/atlas_quant/stat_arb.py` 在 `_signals` 内由 z-score/半衰期直接生成状态，再经投影归一为仓位；报告 `predictions` 为 null。
- 现有附加因子主要改变对冲投影空间，没有训练本协议的 F_h。
- `edge/validation.mjs` 为 stat_arb 保存的 `factor_score` 与 `horizon:5` 是兼容配置，并未定义或生成预测。
- 旧 `factor_score` 路径也可能直接排名建仓，不能仅因报告有分数而满足新协议。
- 当前报告和已发布的 v0.3 实验均不构成本协议的验收证据。

后续实现依次为：

1. 版本化预测配置、冻结目标/标签及模型接口，首先选定一个真实可核对的目标和一个机制模型。
2. 独立生成样本外预测，完成朴素基线对照与预测误差诊断；不运行交易也能完成一次因子研究。
3. 将已有成本与现金/头寸账本接到预测产物，禁止新研究通过 z-score 或其他裸信号绕过预测层。
4. 五步界面改为“股票池 → 因子与状态 → 预测目标与模型 → 执行与成本 → 检验与报告”。普通用户和 Studio 共享同一预测协议。
5. 以独立构造的数值例子、未来数据扰动、边界标签、冻结篮子、T+1 和交易账本检查验证，再进行真实数据及托管验收。

历史配置与报告按原版本保留，不能补造当时不存在的预测；迁移必须显式生成新的实验。尚未实现的预测能力不得通过修改标签提前展示为可用。
