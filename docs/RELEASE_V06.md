## 本版范围

- 完整私有 TAR 复现包可从已完成的研究下载，包含不可变 manifest 与全部已登记分片。严格标准库导入核对大小、路径、哈希、边界及数学关系，再原子发布到新目录。冻结预测执行包明确保留对原始预测输入包的依赖。
- Studio 由与 Python 共用的 18 个算子合同解析实际表达式，显示来源字段、窗口、缺失值处理及可用时点；代码修改后旧解释失效。确定性规则与真实 AI 意见分开展示，AI 文字不作为算子事实。
- 原生财报计算核心提供 15 个字段、16 个状态定义，保留单位、披露时点、期间推导和逐值来源。该核心尚未接入公开研究输入，定义数量不表示可用数据覆盖。

实现和独立检查记录见 [BUNDLE_EXPORT.md](BUNDLE_EXPORT.md)、[STUDIO_DSL_SEMANTICS.md](STUDIO_DSL_SEMANTICS.md) 与 [FINANCIAL_STATEMENTS_CORE.md](FINANCIAL_STATEMENTS_CORE.md)。

## 实际验收

集成源码通过 645 项 Python、128 项 Node、六组页面流程/DOM，以及 16 条确定性、冻结预测、独立执行与审计命令。GitHub 两项 Linux CI 都通过。部署前保存正式 Worker 与数据库状态；暂停新领取、确认在途任务和持久投递为空后切换。此次未迁移数据库，六项绑定、私有配置、精确依赖和 Standard 调度均保留，旧引擎留作备份；读回后恢复队列。

首个正式 Worker 为 1,329,555 字节，SHA-256 `0eed0c4162fde6eec0a3707c62d766cad41fe6862ca3b3499946aa466796cf53`。正式下载既有 50 股八年合成研究的完整 TAR：60,082,176 字节、37 个文件，SHA-256 `4ed6cc1afd029d32e535d2fa2b60eba4541f38805a61d5ed4733b879b4bdec26`。使用 `python -S` 严格导入后 424,135 项独立检查通过，完整保留 19,700 条主预测、19,700 条对照、394 日账本；此下载没有重新拟合或调用 provider。

正式浏览器的 `returns(close,20)` 显示真实累计变化公式 `x[t]/x[t−20]−1`、交易日网格、两端缺失处理和时点规则。一次真实 Workers AI 调用返回了正确的 20 周期描述，来源为 `@cf/qwen/qwen2.5-coder-32b-instruct`，代码哈希 `737e7a4eb8de9bb457d4b44661f0487ebe4145aeab71d56189e88e6f2c43d601`；没有为了更好回答重试，也不以这一例证明 AI 总是正确。旧真实 Tushare 报告与冻结执行记录在正式浏览器仍可读取。

Studio 的实际 390px 布局在本地候选已验收；正式浏览器本次视口覆盖没有生效，实际仍为 1280px，因此这里只确认正式桌面检查，不把截图文件名当作移动端证据。正式截图、下载包、独立审计及部署记录保存在本机受限目录，不放入公共源码。
