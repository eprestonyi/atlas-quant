## 产品目标

将旧 Quant 的默认研究流程替换为独立的“统计量化交易”工作区。一个明确的模型协议贯穿普通用户界面、Studio、Python 引擎、API、数据库和报告：

```text
V[t,h] = F_h(X_t) ≈ E[P[t+h] | I_t]
e[t,h] = P[t] - V[t,h]
predicted_change[t,h] = -e[t,h]
realized_change[t,h] = -e[t,h] + forecast_error[t,h]
```

P 可为资产价格或严格定义的冻结数量篮子。每次模型预测先形成独立可审计的产物，执行层只能引用该产物。纯因子分数、z-score、PCA 载荷不得直接变成新研究的仓位。

Pair trade、均值回归、趋势外推、事件反应、基本面条件预测是不同 F/状态/目标的模型族；对冲、波动率管理、暴露约束、成交与费用是独立组合执行模块。PCA 本身不承诺均值回归。做市、波动率/衍生品、复制关系/结构套利是未来独立工作区，本轮只保留清晰扩展边界，不冒充已实现。

质量按真实模块职责、模型有效实现、互操作性和验收证据衡量。大量组合配方可以由版本化模块组合产生，必须区分“原子模块”“配置组合”“已运行实验”“已验证策略”。不将重复 JSON、目录字段数或参数乘积宣称为独立 alpha。
