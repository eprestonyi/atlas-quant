# 首个完整 300 证券数值实验

本次仅为本地合成数据容量验收，没有调用 provider、提交云端研究、开启组合执行或修改公开上限。完整派生证据见 [phase-b-300-validation.json](phase-b-300-validation.json)，实现边界见 [CAPACITY_CORE.md](CAPACITY_CORE.md)。

配置在运行前固定：300 个合成代码、2023-01-01 至 2025-12-31、783 个工作日、16 个表达式、每日观察、5 日目标、504 日训练窗、20 日重拟合、20% 终段、两个 Ridge 候选及 2×2 嵌套验证。全部证券共用一个 pooled 双输出模型；主模型和状态基线分别选择、拟合。未按结果重挑参数或证券池。合成代码不是沪深300成分，工作日日历不是官方交易日历。

RSS 使用子进程 `ru_maxrss` 的峰值；每 0.5 秒采样的父监督器读数略低，不能将采样值当真实峰值。原始报告的逻辑字节数包含 forecast，而 bundle 中 forecast 内容只保存一份，不能将各 document 长度直接相加当物理传输量。

监督器保留 900 秒总时长、300 秒单次拟合、3 GiB RSS、400 MiB 全部产物及 500 MiB 系统余盘约束。运行前可用磁盘约 2.27 GiB，硬件内存 16 GiB；同机没有另一大型拟合。阶段检查和监督器均未触发，未重跑或放宽预算。

主模型 MSE 为 `0.0005448329138273951`，价格不变基准为 `0.0005380532309143989`，相对改善 **−1.26%**。加入16因子相对单独选模的状态基线，配对日期等权 MSE 改善 **−0.337%**。这些较差结果均完整保留；本实验不提供 alpha、统计显著性或收益能力证据。
